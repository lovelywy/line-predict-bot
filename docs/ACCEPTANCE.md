# Acceptance Checklist

- [ ] Signature ผิดได้ HTTP 401 และไม่สร้างข้อมูล
- [ ] Webhook event เดิม/LINE message ID เดิมส่งซ้ำ ไม่หักแต้มซ้ำ
- [ ] ผู้เล่นพิมพ์คำสั่ง Admin ถูกปฏิเสธ
- [ ] สมัครซ้ำไม่ได้แต้มเริ่มต้นเพิ่ม
- [ ] `/รับแต้ม` ได้วันละครั้ง
- [ ] ทายเกินแต้มคงเหลือถูกปฏิเสธ, ทายซ้ำในรอบเดียวกันถูกปฏิเสธ
- [ ] ทายหลัง `/ปิดรอบ` ถูกปฏิเสธ, `/เฉลย` ก่อน `/ปิดรอบ` ถูกปฏิเสธ
- [ ] ลง 200 @ x1.5 ทายถูกได้คืน 300, ทายผิดเสีย 200
- [ ] `/ยกเลิกรอบ` คืนแต้มทุกคน
- [ ] ผลรวม `point_ledger` ของผู้เล่นแต่ละคนเท่ากับ `players.points`
- [ ] ไม่มีคำสั่งหรือข้อความใดพูดถึงเงิน ฝาก ถอน หรือแลกรางวัล

# Command Reference — LINE Predict Bot

เกมทายผลแบบเล่นฟรี ใช้ **แต้ม** เท่านั้น แต้มไม่มีมูลค่าเป็นเงิน ซื้อ ขาย โอน หรือแลกเป็นเงิน/ของรางวัลไม่ได้ และ Admin เพิ่มแต้มให้ใครไม่ได้

## ผู้เล่น

| คำสั่ง | ใช้ที่ไหน | ความหมาย |
|---|---|---|
| `สมัคร สมชาย` | กลุ่ม | สมัครและรับแต้มเริ่มต้น (ค่าเริ่มต้น 1,000 แต้ม ครั้งเดียว) |
| `ทาย 1 100` / `ทาย2 250` | กลุ่ม | ทายตัวเลือกข้อ 1 ลง 100 แต้ม (รอบละ 1 ครั้ง) |
| `/รอบ` (หรือ `/สถานะ`) | กลุ่ม | ดูคำถาม ตัวเลือก ตัวคูณ และจำนวนผู้ทาย |
| `/อันดับ` | กลุ่ม | ตารางคะแนน 10 อันดับแรกของกลุ่ม |
| `/รับแต้ม` | ทั้งสอง | รับแต้มฟรีรายวัน (ค่าเริ่มต้น 100 แต้ม วันละครั้ง ตามเวลา Asia/Bangkok) |
| `/แต้ม` | แชตส่วนตัว | ดูแต้มคงเหลือ |
| `/ประวัติ` | แชตส่วนตัว | ดูการทาย 10 ครั้งล่าสุด |
| `/ช่วย` | ทั้งสอง | แสดงคำสั่ง |

## Admin

| คำสั่ง | ตัวอย่าง | ความหมาย |
|---|---|---|
| `/ตั้งแอดมิน KEY ชื่อ` | `/ตั้งแอดมิน abc... ลี่` | ตั้ง Admin คนแรกในแชตส่วนตัว |
| `/เริ่มกลุ่ม` | `/เริ่มกลุ่ม` | เปิดใช้งาน Bot ในกลุ่ม |
| `/เปิดรอบ คำถาม \| ตัวเลือก [xN] \| ...` | `/เปิดรอบ ใครชนะ? \| แดง x1.5 \| น้ำเงิน x2 \| เสมอ x5` | เปิดรอบใหม่ 2–6 ตัวเลือก ไม่ระบุตัวคูณ = x2 |
| `/ปิดรอบ` | `/ปิดรอบ` | ปิดรับคำทำนายและสรุปจำนวนผู้ทาย |
| `/เฉลย ข้อ` | `/เฉลย 1` | ประกาศคำตอบและแจกแต้ม (ต้อง `/ปิดรอบ` ก่อน) |
| `/ยกเลิกรอบ` | `/ยกเลิกรอบ` | ยกเลิกรอบที่ยังไม่เฉลยและคืนแต้มที่ลงทั้งหมด |

## กติกาแต้ม

- ลงแต้มเมื่อทาย: หักแต้มทันที
- ทายถูก: ได้คืน `แต้มที่ลง × ตัวคูณ` (ปัดเศษครึ่งขึ้นเป็นจำนวนเต็ม) เช่น ลง 200 @ x1.5 ได้ 300
- ทายผิด: เสียแต้มที่ลง
- ยกเลิกรอบ: คืนแต้มที่ลงเต็มจำนวน
- ทุกการเปลี่ยนแต้มถูกบันทึกใน `point_ledger`

Parser ไม่เดาข้อความกำกวม เช่น `ทาย 1 100 เลย` หรือ `ทาย 0 100` จะถูกเพิกเฉย
